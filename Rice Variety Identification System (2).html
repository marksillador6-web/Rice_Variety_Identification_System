4. About This Project

Rice Variety Identifier is an educational image-classification prototype. It uses a trained image model to predict which supported rice variety may appear in a photo.

  1. Capture a photo or select an image from the gallery.
  2. Tap Identify Rice Variety.
  3. Review the prediction and model confidence.
  4. Check the alternative predictions if available.
  5. Review previous scans or export the scan history.
Important information
Predictions depend on the model's training data and image quality. A high confidence score does not guarantee a correct identification. The application may misclassify unfamiliar objects.
